# 📚 StudySync – Learning Management System

StudySync is a Django-based Learning Management System (LMS) developed for students, instructors, and administrators. The project helps manage courses, lessons, quizzes, and student performance through a role-based system.

---

# 🚀 Features

## 👨‍🎓 Student Module
- Student registration and login
- Access courses and lessons
- Attempt quizzes and assessments
- View quiz scores and performance

## 👨‍🏫 Instructor Module
- Create and manage courses
- Upload lessons and study materials
- Create quizzes and questions
- Track student progress

## 👨‍💼 Admin Module
- Manage students and instructors
- Monitor system activities
- Manage overall platform operations
